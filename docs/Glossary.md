# Глоссарий

- **Аппарат / craft** — один общий космический аппарат команды. Состоит из корпуса (frame) и модулей в слотах.
- **Слот / slot** — монтажное место на корпусе определённого отдела. В 3D — пустой узел `slot_<отдел>_<n>` в GLB корпуса.
- **Модуль / компонент** — карточка каталога, установленная в слот. Может стоять в нескольких экземплярах до `maxInstances`.
- **Тик** — игровой интервал симуляции (1 тик = 10 игровых минут ≈ 1 с реального времени в полёте).
- **Генерация / Потребление / Ёмкость / Заряд** — четыре разные величины энергетики, см. [Energy Model](03%20Design/Energy%20Model.md).
- **RTG / РИТЭГ** — радиоизотопный термоэлектрический генератор. Не реактор.
- **Team Trust** — доверие к командиру. Падает только за сознательное игнорирование предупреждения, если риск сработал.
- **Blackout** — потеря связи с аппаратом; роли видят разные части информации.
- **Tactical Radio** — быстрые текстовые фразы вместо голосового чата.
- **Autonomy Planner** — экран правил «ЕСЛИ … И … → ТО …».
- **Safe Protocol** — базовый безопасный протокол, если команда не настроила правила или не успела решить.
- **MC (Mission Credits)** — мета-валюта между попытками. Не путать с **бюджетом миссии** (М$), который тратится на сборку.
- **Хост** — игрок, создавший комнату. Его клиент — авторитет состояния (см. [Multiplayer](04%20Tech/Multiplayer.md)).
