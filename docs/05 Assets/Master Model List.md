# Полный список моделей (~70)

Легенда приоритета: **P0** — нужен для среза Титана · **P1** — полная игра · **P2** — полировка.
Узлы — обязательные именованные узлы в GLB (см. [3D Pipeline](../04%20Tech/3D%20Pipeline.md)).
