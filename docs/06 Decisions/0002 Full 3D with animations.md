# 0002 Полноценное 3D с анимациями — принято (2026-11-13)
**Контекст:** ТЗ описывает 2D-интерфейс с SVG-иллюстрациями. Мы хотим полноценную игру с 3D-моделями и анимациями.
**Решение:** игра в 3D (three.js / react-three-fiber). Модели — Claude Design → GLB. Интерфейс панелей — 2D поверх 3D.
**Почему:** 3D делает последствия видимыми (модуль на корпусе, светящаяся перегретая линия, рука берёт образец) и делает игру «настоящей».
**Риски:** время на модели, производительность на телефонах. Меры: заглушки-примитивы (игра играбельна без моделей), Low-качество для телефонов, механика процедурная, P0 3D ≈ 30 моделей.
**Альтернативы:** 2D SVG по ТЗ (отклонено пользователем).
