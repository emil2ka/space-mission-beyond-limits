# 0006 Кризисы зависят от сборки — принято (2026-11-13)
**Контекст:** ТЗ не говорит, случайны ли кризисы.
**Решение:** у каждого кризиса есть триггер от сборки/состояния (перегрузка шины, тепло, отсутствие щита…), плюс небольшой шум от сида комнаты.
**Почему:** игра обучающая — отчёт должен честно объяснять «это случилось из-за X». Случайные аварии ломают причинность.
