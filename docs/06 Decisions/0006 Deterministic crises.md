# 0006 Crises depend on the build — accepted (2026-11-13)
**Context:** the spec (TZ v2.0) does not say whether crises are random.
**Decision:** every crisis has a trigger based on the build/state (bus overload, heat, missing shield…), plus a little noise from the room seed.
**Why:** this is an educational game — the report must honestly explain "this happened because of X". Random failures break causality.
