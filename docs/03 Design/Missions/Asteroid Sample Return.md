# ASTEROID: SAMPLE RETURN

**Цель:** сблизиться с астероидом, собрать физический образец, сохранить и вернуть на Землю.
**Доступ:** за Mission Credits, заработанные на Титане (см. [Economy](../Economy.md)).
**Среда:** практически нет атмосферы — пропеллеры не работают; точная навигация и ориентация; ограниченное топливо; риск повреждения механизма отбора.

## Ограничения (стартовые, условные)
| Параметр | Значение |
|---|---|
| Бюджет | 480 М$ |
| Лимит массы носителя | 740 кг (корпус 280 кг, 90 М$) |
| Слоты | энергия 6 · двигатели 4 · навигация 4 · наука 4 · связь 4 · корпус 4 · возврат 4 |
| Солнце | ×0.6 (зависит от ориентации) |
| Задержка связи | 3 тика |

## Двигатели
- Химические (Main Engine, Thruster Cluster) — резкие манёвры сближения, расходуют топливо.
- Ion Engine — длительный перелёт эффективно, но **не заменяет** двигатель для резких манёвров.
- Rotor System — **несовместим**: «Пропеллеры не создают подъёмную силу в вакууме». Не засчитывается как двигатель (приёмочный тест B).

## Обязательные системы
Chemical Main Engine или Chemical Thruster Cluster · Propellant Tank · Reaction Wheels или Thruster Cluster (ориентация) · Robotic Arm или Drill · Sample Container · Return Capsule · Heat Shield · Parachute/Recovery System · Flight Computer · связь.
**Рекомендуется:** Sample Sealing Unit, Radar/Altimeter, Navigation Camera, Star Tracker, Micrometeoroid Shield, Recovery Beacon.
**Бесполезно:** Atmospheric Sensor, Rotor System, Heater (почти не нужен).

## Фазы полёта
1. **Перелёт** (ионный или химический — разный расход топлива и время).
2. **Сближение** — навигация, ориентация, Debris Alert возможен.
3. **Выбор места** — учёный выбирает 1 из 3 точек (мягкий реголит / камень / рядом с трещиной).
4. **Отбор образца** — рука/бур, Sampling Arm Jam возможен.
5. **Упаковка** — контейнер, герметизация.
6. **Обратный перелёт** и **возвращение капсулы** — щит, парашют, маяк.

## Успех
Perfect: образец герметичен + капсула найдена + данные состава доставлены. Partial: данные есть, образец потерян.

## 3D-сцена
Чёрный космос, звёзды, медленно кувыркающийся астероид (неровный, с кратерами), маленькие струи двигателей ориентации, рука с пылью при отборе, вход капсулы с раскалённым щитом и раскрытие парашюта над океаном/степью.
