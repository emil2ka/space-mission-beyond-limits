# Звук

> 2026-11-15, M5. Код: `src/audio/` (движок, логика событий), кнопка настроек — `src/ui/components/SoundSettings.tsx`. Статус: **проверено** тестами и в браузере (сигнал на выходе, события, громкость); **на слух не проверено** — см. «Как послушать».

## Принципы
- **Все звуки синтезируются в коде** (WebAudio: осцилляторы, шум, фильтры). Никаких файлов и лицензий, ноль байт в сборке.
- Настроение — как у визуала ([Style Guide](Style%20Guide.md)): уютный «игрушечно-премиальный» sci-fi. Мягкие синусы и треугольники, тихий фон, без хоррора и без сирен.
- **Ничего «наказывающего»:** зуммер кризиса — 2 коротких импульса (≈0.45 с), не бесконечная сирена; провал миссии — мягкий тёплый аккорд («попробуем ещё»), а не «фейл»-звук.
- Громкость ограничена: общий потолок микса + мягкий лимитер (компрессор) на выходе. По умолчанию: общая 60 %, фон 50 %, эффекты 70 %.
- Экраны о звуке не знают: всё берётся из изменений состояния комнаты (`src/store/game.ts`). Отдельный вызов `playUi()` есть, но экраны его не используют. Тихий «тик» на любую кнопку — делегированный обработчик клика (`data-no-click-sound` на контейнере отключает).

## Когда что звучит
**Фон (непрерывные слои, плавные переходы ~0.6 с)**
| Где | Звук |
|---|---|
| Главный экран, лобби, брифинг, конструктор, проверка, штаб, отчёт | Гул штаба: сетевой гул 55/110 Гц + «кондиционер» (коричневый шум) |
| Запуск | Ночной ветер у стартового стола + последовательность старта (ниже) |
| Перелёт (оба), Астероид до возвращения | Космос: глубокий спокойный дрон + тихое мерцание |
| Титан после входа | Ветер (полосовой шум с «дыханием») + метановый дождь; в буре дождь сильнее |
| Титан, ротокоптер летит | Лопасти «вуп-вуп» (шум, промодулированный 17 Гц) + тон мотора |
| Астероид, перелёты | Ионный двигатель — тихий двойной тон; химический — низкий рокот |
| Астероид: сближение, место, отбор, упаковка | Импульсы двигателей ориентации — короткие шипящие «пшик» раз в 1–4 с |
| Вход в атмосферу (Титан: фаза входа; капсула: entry, слабее на парашюте) | Плазменный рокот |
| После посадки капсулы | Лёгкий земной ветер |
| Связь: SIGNAL LOST / INTERFERENCE | Радиошум (полный / половина) — идёт в шину эффектов: это информация |

**Разовые звуки**
| Событие (состояние) | Звук |
|---|---|
| Модуль поставлен / снят (конструктор) | Короткий «клац» вверх / вниз |
| Утверждение командира | Мягкий мажорный арпеджио-колокольчик |
| Вето | Две спокойные нисходящие ноты |
| Старт (`stage → launch`, тайминг = `launchTimeline.T`) | 3 бипа отсчёта, высокий бип «СТАРТ!», рёв двигателей с раскрытием фильтра, низкий гул отрыва, «бум» отделения ступени, вторая ступень тише, щелчок обтекателя |
| Новая фаза полёта | Тихий двойной колокольчик |
| Кризис начался | **Короткий зуммер** (2 импульса) + **тихий радиошум** 1.4 с — по [Crises and Blackout](Crises%20and%20Blackout.md), п. 6 |
| Кризис закрыт: причина устранена / нет | Восходящая пара нот / одна нейтральная нота |
| Tactical Radio доставлено | Бип открытия эфира → шум → бип закрытия; аварийная фраза — двойной бип |
| Связь потеряна / вернулась | Нисходящий тон + шум / два восходящих бипа |
| Захват образца | Сервопривод + стук |
| Рука заклинила | Короткий «скрежет» + стук |
| Контейнер загерметизирован | Щелчок + шипение |
| Капсула отделилась / парашют / посадка / маяк найден | Пиро-«тук» / свист + хлопок купола / глухой удар / 3 мягких бипа |
| Отчёт: Perfect / Success / Partial / Failed | Аккорд + арпеджио колокольчиков / мажорный аккорд / открытый Csus2 / мягкий Fmaj7 |

Чего нет специально: звука на каждый тик, звука при перезагрузке или подключении в середине кризиса (первое состояние комнаты — без событий), звуков в 3D-повторе отчёта.

## Настройки (кнопка с динамиком, левый верхний угол, на всех экранах)
- **Звук вкл/выкл**, **Общая**, **Фон** (фон/музыка), **Эффекты** — ползунки 0–100, хранятся в `localStorage` (`sm:soundOn`, `sm:volMaster`, `sm:volAmbience`, `sm:volSfx`, `sm:softSounds`) через `src/ui/settings.ts`.
- **Без резких звуков:** зуммер кризиса заменяется мягким двухнотным сигналом, радиобипы ниже, радиошум и помехи вдвое тише, эффекты чуть тише. Reduced Motion на звук не влияет.
- «Проверить звук» — короткий колокольчик.
- В той же панели — Reduced Motion, Disable Flash, качество графики (общий `A11yToggles`): это экран 19 «Настройки доступности».
- Dev (`pnpm dev`): раздел «dev: аудио» — состояние AudioContext, активные слои, выпадающий список всех звуков с кнопкой ▶ и журнал последних событий (`▶` сыграно, `·` пропущено и почему). В консоли — `[audio] …` (debug), `window.__smAudio.level()` — уровень на выходе в dBFS.

## Браузер и вкладки
- **Автовоспроизведение:** AudioContext создаётся на первом настоящем клике/клавише (pointerdown/keydown), до этого игра молчит.
- **Локальный режим** (все игроки — вкладки одного браузера) и главный экран: звучит **только вкладка в фокусе** (`document.hasFocus()`), и фон, и эффекты — никакой какофонии из 4 вкладок. Переключились на другую вкладку и кликнули — звук переходит туда.
- **Онлайн:** звучит любая видимая вкладка (у каждого игрока своё устройство).

## Как устроено
- `src/audio/events.ts` — чистые функции: `snapshotOf(room)` (плоский снимок того, что важно для звука), `soundEvents(prev, next)` → разовые звуки, `layersFor(snapshot)` → уровни фона, `audibility(mode, focus, visible)`. Тесты: `src/audio/__tests__/events.test.ts`.
- `src/audio/engine.ts` — синтез: шины `ambience` и `sfx` → `master` → компрессор → выход; петли запускаются/гасятся плавно, старт расписан по времени `AudioContext`.
- `src/audio/index.ts` — `startAudio()` (вызывается один раз в `App.tsx`): подписка на `useGame` и `useSettings`, фокус/видимость, разблокировка жестом.

## Как послушать (вручную, нужны уши)
1. `pnpm dev`, открыть `http://localhost:5188/?dev=1&speed=10` в обычном браузере, в **одной** вкладке, наушники на средней громкости.
2. Кликнуть динамик (левый верхний угол) — должен начаться тихий гул штаба. В «dev: аудио» прослушать все звуки по списку ▶. Проверить: зуммер не режет уши, «Без резких звуков» заметно мягче, Failed звучит спокойно, а не «наказывающе».
3. Подвигать ползунки: «Общая» в 0 — тишина; «Фон» в 0 — гул пропал, эффекты остались; снять «включён» — тишина сразу.
4. Создать демо-комнату, собрать аппарат (клац на каждый модуль), утвердить → старт: отсчёт совпадает с цифрами 3-2-1, рёв — с пламенем, «бум» — с отделением ступени.
5. Титан: дождь и ветер после входа, лопасти, пока ротокоптер летит, в буре дождь сильнее; потеря связи — шум. Астероид: «пшики» двигателей у астероида, капсула — рокот входа, парашют, удар, маяк.
6. Открыть вторую вкладку той же комнаты, кликнуть в неё — первая должна замолчать.
