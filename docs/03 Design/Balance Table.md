# Таблица баланса

Все числа — условные игровые параметры, не реальные характеристики NASA. Источник правды — код: компоненты `src/engine/data/components.ts`, миссии `src/engine/data/missions.ts`, полёт Титана `src/engine/data/titan.ts`, Астероида `src/engine/data/asteroid.ts`, экономика `src/engine/data/economy.ts`. Эта таблица их описывает; при расхождении прав код.

## Перегруз массы
| Перегруз | Последствие |
|---|---|
| до +10 % | предупреждение; на входе корпус −3 % за каждый 1 % (макс. −25), роторы +3 % мощности, скорость −2 % за 1 % |
| больше +10 % | блокер: носитель не поднимет |

## Оценка и награды
| Критерий | Вес | Как считается |
|---|---|---|
| Главная научная задача | 35 | доля доставки двух лучших целей |
| Объём и качество данных | 20 | ½ объём собранного + ½ качество |
| Состояние аппарата | 10 | корпус %, −20 % за каждый отказавший прибор |
| Работа связи | 15 | доставлено / собрано |
| Доп. цели | 10 | доставка остальных двух целей |
| Завершение маршрута | 5 | пройденные точки / 3 |
| Расход ресурсов | 5 | полный балл до 85 % бюджета, на 100 % — половина |
≥ 90 Perfect · ≥ 70 Success · ≥ 40 Partial · иначе Failed. MC: 120 / 90 / 50 / 20 + 10 за каждую доставленную цель. Подготовка к следующей попытке — см. «Экономика» ниже. Team Trust: −15 за каждое принятое предупреждение, риск которого сработал, +10 за чистый полёт (см. «Team Trust» ниже).

## Полёт Астероида (M3, `ASTEROID` в `src/engine/data/asteroid.ts`)
| Параметр | Значение |
|---|---|
| Фазы (максимум) | Перелёт ≤ 140 · Сближение ≤ 120 · Выбор места 40 · Отбор 100 · Упаковка 30 · Возвращение 190 тиков |
| Длина полёта | 541–590 тиков ≈ 9–10 мин (химия быстрее, ион дольше) |
| Перелёт | Ion Engine 140 тиков, 0.07 топлива/тик (ест 60 W) · химия 100 тиков, 0.4/тик |
| Сближение | 80 тиков с Navigation Camera или Radar, 110 без; 0.3 топлива/тик |
| Топливо | 100 ед. на Propellant Tank; удержание у поверхности 0.05/тик; импульс домой химия 30 / с ионом 5 + 0.07/тик; перегруз ×(1 + 3 × доля) |
| Типичный расход | химия ≈ 101 (2 бака с запасом, 1 бак — впритык, с уклонением не хватит) · ион ≈ 60 (1 бак) |
| Отбор | рука тянется 12 тиков; скорость за тик: реголит рука 1/35 бур 1/45 · камень 1/80 / 1/40 · трещина 1/50 / 1/45; рука + бур = лучший + ½ второго; к концу фазы ≥ 40 % → частичный образец |
| Образец | реголит 60 г · камень 40 г · трещина 50 г; полный балл от 40 г; герметизация 20 тиков |
| Капсула | отделение 130 · вход 140 · парашют 155 · посадка 170 (тики фазы); найдена +3 с маяком, +15 без маяка (если в расчётной точке), иначе не найдена |
| Память / связь | как Титан: 20 ед. + Storage/Buffer, `bandwidth × 1/6` ед./тик, задержка 3 тика |

### Места отбора
| Место | Риск заклинивания (база) | Данные состава | Качество |
|---|---|---|---|
| Мягкий реголит | 0.35 | ×0.8 | 0.8 |
| Камень | 0.8 | ×1 | 1 |
| Рядом с трещиной | 0.6 | ×1.3 | 1 |
Риск: −0.6 с Vibration Dampers, +0.3 без (+0.1 ещё с буром), +1 если рука погнута обломками. ≤ 0 — никогда, ≥ 1 — всегда; момент 20–50 % набора — из сида.

### Научные цели Астероида
| Цель | Нужно | Прибор → ед./тик |
|---|---|---|
| Состав астероида (нужен для Perfect) | 45 | Spectrometer: сближение 0.05, место 0.2, отбор 0.35 (после касания), упаковка 0.5 (из образца) · Drill: отбор 0.15 (качество 0.6) |
| Съёмка места отбора | 35 | HiRes: 0.2 / 0.6 / 0.1 · Wide: 0.25 / 0.35 / 0.1 (кач. 0.75) · Navigation Camera: 0.15 / 0.4 / 0.1 (кач. 0.6) |
Слотов науки 4 (рука, контейнер, герметизатор, спектрометр — уже 4), поэтому место снимает и Navigation Camera (отдел навигации).

### Кризисы Астероида
| Параметр | Значение |
|---|---|
| Таймер | 20 тиков (Debris без Radar / Navigation Camera — 8) |
| Debris Alert | тик 15–45 сближения (сид); без Micrometeoroid Shield всегда, с ним 25 % сидов |
| Урон обломков | без щита −18 %, со щитом −4 %; замереть ×0.5; щитом к потоку /3; укрыть капсулу +4 % корпусу, но Heat Shield цел; без щита и укрытия — Heat Shield повреждён (+ рука погнута, если «продолжить»); лёгкие сплавы ×1.25 |
| Уклонение | −12 топлива, сближение +8 тиков; без Star Tracker / Reaction Wheels антенна теряет Землю на 8 тиков |

| Общие кризисы | Power Drop / Overheat / Freeze по правилам Титана, не больше 2 на Астероиде |

### Оценка Астероида
| Критерий | Вес | Как считается |
|---|---|---|
| Главная научная задача | 35 | 0.6 — образец на Земле (капсула найдена) + 0.4 — доля доставки данных состава |
| Объём и качество данных | 20 | как Титан |
| Состояние аппарата | 10 | как Титан |
| Работа связи | 15 | как Титан |
| Сохранность образца | 10 | герметичен 1 / нет 0.5 × min(1, масса/40 г) × 0.5 при перегреве |
| Возвращение капсулы | 5 | найдена 1 / не найдена 0.3 |
| Расход ресурсов | 5 | ½ бюджет + ½ остаток топлива (полный от 10 %) |
Perfect — только при герметичном образце + найденной капсуле + доставленном составе; без образца на Земле — максимум Partial.
